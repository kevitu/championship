# Official image assets — KEVITU

The frontend expects these five original logos (optimised WebP):

- `assets/img/brand/kevitu-logo.webp`
- `assets/img/houses/rumah-merah.webp`
- `assets/img/houses/rumah-biru.webp`
- `assets/img/houses/rumah-hijau.webp`
- `assets/img/houses/rumah-kuning.webp`

The images are **not uploaded here yet**. An upload-ready ZIP has been prepared from five user-supplied images. Upload extracted images into matching directories using GitHub **Add file → Upload files**; do not upload the ZIP as the image asset. Until then, cards render a fallback symbol on image load errors.

No official sports points are included in these image assets.
